◆package.jsonのアップデート方法
以下の順番でコマンドを実行
・npm outdated　// 各パッケージの現在のバージョンと最新バージョンを比較
・ncu　// 各パッケージの依存関係を考慮しつつ、利用可能な最新バージョンを一覧表示
・ncu -u　// "ncu"で表示された利用可能な最新バージョンにpackage.jsonを書き換え
・npm install　// package.jsonの内容に更新




◆composer.jsonのアップデート方法
以下の順番でコマンドを実行
・composer outdated　// 現在インストールされているバージョンと最新バージョンの差を一覧表示
・composer update --dry-run　// アップデート可能なパッケージとそのバージョンを表示
・composer update　// アップデート実施
※ composer.json内に記述されている各パッケージやライブラリのバージョンを書き換えてくれない
























xamppでphpのバージョンを変更する方法を教えて
PCはwindowsです。
Windows版XAMPPでPHPのバージョンを変更するには、主に以下の2つの方法があります。
方法1：PHPフォルダを差し替える（手動アップデート）
現在のXAMPP環境を維持したまま、PHPの実行ファイルだけを入れ替える方法です。 
バックアップ: XAMPPフォルダ（通常 C:\xampp）内の php フォルダを、php_old などにリネームして残しておきます。
新バージョンの入手: PHP For Windows から、目的のバージョンの Thread Safe版（Zipファイル） をダウンロードして解凍します。
配置: 解凍した中身を新しい php フォルダとしてXAMPPフォルダ内に配置します。
設定の引き継ぎ:
旧フォルダから php.ini をコピーして新フォルダへ移します。
apache/conf/extra/httpd-xampp.conf を開き、PHPのパス（例: php7apache2_4.dll から php8apache2_4.dll）を新バージョンに合わせて書き換えます。
再起動: XAMPP Control PanelからApacheを再起動してください。 
方法2：別バージョンのXAMPPを並行インストールする（推奨）
設定の書き換えによるエラーを防ぐため、異なるバージョンのXAMPPを別のディレクトリにインストールする方法が安全です。 
Apache Friends から、目的のPHPバージョンが含まれるXAMPPをダウンロードします。
インストール時に、既存のXAMPP（C:\xampp）と重ならないよう、C:\xampp_php81 などの別フォルダを指定してインストールします。
利用したいバージョンのXAMPPコントロールパネルから起動することで、簡単に使い分けが可能です。 
注意点:
手動で行う場合は、必ず事前に htdocs やデータベース（mysql/data）のバックアップを取ってください。
複数のXAMPPを同時に起動することはできません（ポートが競合するため）。 
特定のPHPバージョン（例：PHP 8.2から8.3など）へのアップグレードをご希望ですか？具体的な現在のバージョンと移行先を教えていただければ、より詳細な手順を案内できます。
